# Заметки для Claude

Общение с пользователем — на русском. В репозитории две игры:
- `index.html` — старый 3D-платформер «Небесные острова» (Three.js). Его не трогаем без просьбы.
- `farm/index.html` — **«Остров-ферма»**, 2D pixel-art ферма. Основная работа идёт здесь.

## Остров-ферма: как устроено
Один файл `farm/index.html` (~3500 строк), без сборки и внешних ассетов: вся графика рисуется кодом
(функции `make*()` → canvas → `outline()`), шрифт Press Start 2P с Google Fonts.
Разделы в скрипте помечены комментариями `// ================= ... =================` и `// ---- ... ----`.

- **Мир**: тайлы 16 px, карта `W×H = 82×54`. Острова — `ISL` (0 наш, 1 лесной с озером, 2 коровий),
  форма через `islandV()/landV()` (плюс — суша). Земля пререндерится один раз в `buildGround()`.
- **Состояние** — объект `state`, сохраняется в `localStorage` (`SAVE_KEY = 'ostrov-ferma-v1'`).
  Новые поля добавляй и в `newState()`, и в `migrate()` — у игрока есть старые сохранения.
- **Постройки** — `state.objs` (`type`, `tx`, `ty`, для больших `w`/`h`); грядки — `state.beds`.
  Коллизии построек пересобирает `rebuildDyn()` (вызывать после любых изменений objs).
- **Чертежи** — `PLANS` (мельница 3×3, домик работника и кухня 2×2): размечаются молотком,
  стройплощадка → `openSite()` → `buildSite()`.
- **Сцены**: `state.scene` = `island` или комната из `ROOMS` (house, mill1, mill2, cabin);
  у комнаты свои фон, коллизии, действия, освещение. Панорамы с мельницы — `pano`.
- **Действия**: `getAction()` → `islandAction()` / `RM.action()` возвращает `{hint, run}`; E вызывает `act()`.
  У работника `{worker}` — удержание E открывает `openJobs()`.
- **Время**: `state.t` в игровых минутах (5 мин за секунду, T — ×12). Всё, что зависит от времени, — в `advanceTime(dm)`.
- **Погода**: дождь/гроза (`startRain`), молнии `lightning()`, холод `coldTick()`, камин `fireTick()`.
- **Живность и люди**: курицы `updateChickens`, коровы `updateCows`, рыбы `updateFish`,
  работники `updateWorkers` (поиск пути `findPath` по сетке `tilePass`, задачи `pickTask/doTask`), паром `state.ferry`.
- **Отрисовка**: `renderIsland()` сортирует объекты по `y`; свет и ночь — `applyLighting()`.

## Проверка
Перед коммитом прогоняй все проверки в браузере (Playwright стоит глобально), каждая должна выйти с кодом 0 и `errors []`:
```
for t in farm/tests/*.js; do node $t || echo "FAIL $t"; done
```
Скриншоты кладутся в `$SHOTS` (по умолчанию `/tmp/farm-shots`) — их стоит посмотреть глазами.
