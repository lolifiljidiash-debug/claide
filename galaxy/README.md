# Карта Млечного Пути

Интерактивная 3D-карта нашей Галактики на [Three.js](https://threejs.org/) с серверным управлением освещением.

## Запуск

```bash
cd galaxy
node server.js          # нужен Node.js 18+, зависимостей нет
```

- карта: http://localhost:8080/
- пульт освещения: http://localhost:8080/admin.html

Переменные окружения: `PORT` (по умолчанию 8080), `HOST`, `ADMIN_TOKEN` (если задан, менять свет можно только с токеном), `STATE_FILE` (куда сохранять текущий свет, по умолчанию `lighting-state.json` рядом с сервером).

Без сервера карта тоже работает (например, на GitHub Pages: https://lolifiljidiash-debug.github.io/claide/galaxy/), просто свет настраивается только локально. Нужен интернет: Three.js грузится с CDN.

## Что на карте

- **Галактика** из ~260 000 частиц: бар и балдж, четыре спиральных рукава (Персея, Щита–Центавра, Стрельца–Киля, Наугольника) и местный рукав Ориона, пылевые полосы, сияние ядра, Магеллановы Облака.
- **Объекты в реальных положениях** (по галактическим координатам и расстоянию): Солнце, Проксима и Альфа Центавра, Сириус, Вега, Бетельгейзе, Ригель, Денеб, Полярная, VY Большого Пса, Эта Киля и др.; туманности (Ориона, Крабовидная, Орёл, Лагуна, Кольцо…), скопления (Плеяды, Гиады, Омега Центавра, M13, 47 Тукана), чёрные дыры (Стрелец A*, Лебедь X-1, Gaia BH1).
- **Планетные системы**: Солнечная (8 планет, Плутон, Луна, пояс астероидов и пояс Койпера, кольца Сатурна и Урана), TRAPPIST-1, Проксима Центавра, Альфа Центавра (двойная звезда), Сириус A и B, звезда Барнарда, Эпсилон Эридана, 51 Пегаса, Kepler-186, Kepler-452. Планеты движутся по орбитам, освещены своей звездой и отбрасывают тени. Любую другую звезду можно «рассмотреть вблизи».

Расстояния в системах сжаты, а планеты увеличены, иначе их не было бы видно. Размеры экзопланет, не проходящих по диску звезды, — оценки по массе.

### Управление
| Действие | Как |
|---|---|
| Вращать / приблизить / сдвинуть | левая кнопка / колесо / правая кнопка мыши (на телефоне — пальцами) |
| Выбрать объект | клик по нему или по строке в списке слева; есть поиск |
| Открыть систему | двойной клик по звезде или кнопка в карточке |
| Следить за планетой | клик по планете в системе |
| Назад / вся галактика | Esc / H |
| Пауза и скорость времени | панель внизу в режиме системы, пробел |

## Освещение

Параметры описаны в `lighting.json` (там же пресеты: Стандарт, Кино, Научный, Ночной, Затмение, Неон):
`exposure`, `starLight`, `ambient`, `galaxyBrightness`, `coreGlow`, `dust`, `bloom`, `tint` (цвет), `shadows`, `lockClients`.

Сервер рассылает изменения всем открытым картам через Server-Sent Events, а карта плавно переходит к новому свету. Если включить `lockClients`, зрители не смогут менять свет сами.

Управлять можно тремя способами:

1. **Пульт** — `admin.html`: ползунки, пресеты, число подключённых зрителей.
2. **HTTP API**:
   ```bash
   curl -X PATCH localhost:8080/api/lighting -H "Content-Type: application/json" \
        -d '{"exposure":1.4,"bloom":2,"transition":2000}'     # transition — длительность перехода, мс
   curl -X POST  localhost:8080/api/lighting/preset/eclipse
   curl -X PATCH localhost:8080/api/lighting -d lockClients=true
   curl -X POST  localhost:8080/api/lighting/reset
   curl          localhost:8080/api/lighting                   # текущее состояние
   ```
   С `ADMIN_TOKEN` добавьте заголовок `Authorization: Bearer <токен>`.
   `PUT /api/lighting` заменяет все параметры (то, что не передано, сбрасывается), `GET /api/events` — поток событий, `GET /api/config` — схема и пресеты.
3. **Консоль сервера** — команды прямо в терминале, где запущен `server.js`: `show`, `set exposure 1.5 bloom 2`, `preset night`, `reset`, `lock`, `unlock`, `clients`, `help`.

Карту можно подключить к серверу на другом адресе: `index.html?server=http://мой-сервер:8080`.
